# Samam

**Your document, the same everywhere.**

Samam is a free, privacy-first, browser-based document toolkit. It keeps documents looking the same on mobile, Mac and Windows, and gets files ready for application portals, without licenses, signups or uploading your files.

> Status: planning (Day 0). Not usable yet.

## Why
- Documents break across devices: fonts swap, spacing shifts, resumes spill onto a second page
- Portals reject files for size and format
- Free online tools upload your private files and push paid plans

## Planned features
- Merge, split, reorder, rotate, sign PDFs
- PDF ⇄ images
- Compress to an exact target size (KB) for portals
- Docx to PDF with layout frozen
- All core tools run in your browser; files stay on your device
